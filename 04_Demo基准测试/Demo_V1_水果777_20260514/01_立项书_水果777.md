# 水果777 立项书

## 1. 项目基本信息

- 名称：水果777
- 类型：经典水果 Slot Demo
- 平台：Web H5 原型，后续可迁移到 Unity、Cocos 或原生 WebView
- 目标用户：偏好轻量、快速反馈、强视觉奖励的休闲 Slot 用户
- 项目周期建议：5个工作日完成可演示版本，15个工作日完成可交付灰盒版本

## 2. 核心卖点

- 果汁工厂主题：用玻璃管道、果汁流动、切片转盘区别于传统平面水果机。
- 低门槛：3x3卷轴、5条赔线，用户无需学习即可上手。
- 高反馈：Spin按钮、奖池灯牌、中奖符号、果汁粒子形成连续刺激。
- 可扩展：可平滑扩展到5x3、更多赔线、关卡任务、收集系统和大厅活动。

## 3. 首版Demo目标

| 目标 | 验收标准 |
|---|---|
| 可玩核心循环 | 用户可Spin、扣除下注、结算奖励、余额变化正确 |
| 视觉接近参考 | 有热带果汁、霓虹、奖池、玻璃管道、符号卡片 |
| 特色功能可见 | Wild、Scatter、Bonus、Free Game、Jackpot均有展示 |
| 可沉淀资产 | 策划、美术、动效、程序、测试文档齐全 |

## 4. 风险和边界

- 数值风险：Demo随机逻辑不等于生产RTP模型，正式项目必须由数值策划独立建模和审计。
- 合规风险：真实货币、提现、地区投放、年龄限制和广告素材需要法务确认。
- 美术风险：参考图仅用于方向，不直接复制具体图形构成，正式资产需要重新绘制和授权管理。
- 性能风险：移动端需要控制粒子数量、滤镜层级和阴影范围。

## 5. 人工确认点

1. 是否采用3x3作为首发玩法，还是直接提升到5x3。
2. 是否保留Jackpot视觉，但在Demo里仅做虚拟奖池。
3. 是否需要接入真实音频、美术PSD/Spine工程或Unity工程。
4. 是否进入下一轮Demo V2，并加入关卡任务、收集图鉴和更完整Bonus小游戏。
