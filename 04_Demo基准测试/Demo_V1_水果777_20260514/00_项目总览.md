# 水果777 Demo V1 项目总览

## 交付定位

- 项目代号：水果777
- Demo版本：V1_20260514
- 玩法类型：3x3 经典水果 Slot，虚拟金币演示版
- 主题方向：热带果汁工厂、霓虹奖池、玻璃管道、果片转盘
- 参考目标：快速展示从客户需求到策划、美术、动效、程序、测试的完整链路产出

## 目录结构

| 路径 | 内容 |
|---|---|
| `01_立项书_水果777.md` | 面向项目启动和客户沟通的立项说明 |
| `02_Slot策划案_水果777.md` | 玩法、符号、奖池、触发和数值框架 |
| `03_美术风格与资产清单.md` | UI、符号、背景、特效和交付规格 |
| `04_动效与音效说明.md` | Spin、中奖、奖池、Bonus等表现节奏 |

| `06_测试用例.md` | 基础功能、边界、表现和兼容测试 |
| `demo/index.html` | 可直接打开的单页可玩原型 |

## Demo玩法范围

- 已实现：Spin、Auto、Take、虚拟余额、下注切换、5条赔线、Wild代替、Scatter免费旋转、Bonus奖池、中奖动效、奖池脉冲。
- 未实现：真钱支付、账号系统、后端风控、生产级RTP审计、正式音频文件、商业美术资产。
- 合规提示：当前版本仅作为内部原型和虚拟金币演示，不得直接作为真实博彩产品上线。

## 产出标准

1. 策划可读：能让项目经理、程序、美术、测试直接拆任务。
2. 美术可执行：给出风格关键词、资产清单、尺寸、层级和动效意图。
3. 程序可运行：无需依赖安装，浏览器打开即可体验核心循环。
4. 测试可复核：提供基础路径、边界路径和表现路径测试用例。
