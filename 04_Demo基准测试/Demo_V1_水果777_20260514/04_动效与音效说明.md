# 水果777 动效与音效说明

## 1. 总体节奏

- 单次Spin总时长：900ms到1400ms。
- 第一列先停，第二列延迟120ms，第三列延迟240ms，制造期待感。
- 中奖结算在最后一列停止后200ms触发，避免反馈过早。
- Bonus和Scatter优先级高于普通中奖表现。

## 2. 动效清单

| 事件 | 动效 | 时长 | 备注 |
|---|---|---:|---|
| 入场 | 顶部灯牌下压、果汁转盘亮起、卷轴淡入 | 700ms | 首次打开页面 |
| 点击Spin | Spin橙片按钮压缩、管道气泡加速 | 150ms | 立即响应 |
| 卷轴滚动 | 每列竖向模糊滚动、符号缩放回弹 | 900ms | 分列错峰停止 |
| 普通中奖 | 命中符号放大、描边闪两次、中奖金额跳字 | 900ms | 多线中奖循环高亮 |
| Wild参与 | Wild符号喷出果汁粒，替代符号轻微闪烁 | 600ms | 叠加在普通中奖前 |
| Scatter触发 | 顶部果片转盘旋转一圈，Free计数弹出 | 1200ms | 免费旋转入口 |
| Bonus触发 | 金币震动，随机奖池灯牌脉冲，余额飞字 | 1600ms | 优先级最高 |
| Auto状态 | Auto按钮常亮，Spin按钮显示自动中 | 持续 | 再次点击Auto停止 |

## 3. 音效建议

| 音效 | 描述 |
|---|---|
| ui_tap | 清脆果冻按键声 |
| reel_spin | 轻快机械转动加果汁流动声 |
| reel_stop | 三段不同音高的停止声 |
| win_small | 短促上扬金币声 |
| win_big | 多层金币、气泡和人声点缀 |
| scatter_trigger | 星星扫频、转盘启动 |
| bonus_trigger | 低频冲击、金币倾泻、奖池灯闪 |
| no_credit | 柔和错误提示，不刺耳 |

## 4. 移动端性能约束

- 同屏粒子建议不超过36个。
- 滤镜模糊和大面积阴影只用于关键层。
- 卷轴动画优先使用transform和opacity。
- 可见区域外的装饰不做持续动画。
