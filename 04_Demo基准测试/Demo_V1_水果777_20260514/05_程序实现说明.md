# 水果777 程序实现说明

## 1. 技术方案

- 技术栈：原生HTML、CSS、JavaScript。
- 运行方式：直接打开 `demo/index.html`，无需安装依赖。
- 目标：快速验证玩法循环、界面层级、动画节奏和状态反馈。

## 2. 模块划分

| 文件 | 职责 |
|---|---|
| `demo/index.html` | 页面结构、奖池、卷轴、控制面板 |
| `demo/styles.css` | 主题视觉、响应式布局、动效 |
| `demo/app.js` | 随机结果、赔线结算、状态更新、按钮逻辑 |

## 3. 核心状态

- `credits`：虚拟余额。
- `bet`：当前总下注。
- `lastWin`：最近一次中奖。
- `freeSpins`：剩余免费旋转次数。
- `autoMode`：是否自动Spin。
- `isSpinning`：防止重复点击。
- `jackpots`：Grand、Major、Mini展示值。

## 4. 玩法逻辑

1. 点击Spin。
2. 若无免费旋转，则检查余额并扣除下注。
3. 按权重随机生成3x3结果。
4. 播放三列错峰停止动画。
5. 检查5条赔线，Wild可替代普通符号。
6. 检查Scatter和Bonus触发。
7. 更新余额、奖池、状态文本和高亮。
8. Auto模式下延迟进入下一次Spin。

## 5. 后续扩展建议

- 将随机结果替换为服务端下发结果，前端只负责表现。
- 抽离Math配置为JSON，支持数值策划独立调参。
- 增加音频管理器，按用户交互后解锁WebAudio。
- 接入埋点：Spin次数、下注、中奖、Bonus触发、Auto使用率。
- 增加可视化Debug面板，用于强制触发Scatter、Bonus和大奖。
