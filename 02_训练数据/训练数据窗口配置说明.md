# 训练数据窗口配置说明

训练数据窗口一共 3 个：

- `T-A-成员A训练数据-Slot策划方向`
- `T-B-成员B训练数据-文审机策划方向`
- `T-C-成员C训练数据-策划执行层通用`

## 自定义说明建议

复制下面内容到每个训练数据窗口的自定义说明中：

```markdown
你是公司AI训练数据记录助手。你的任务不是替代成员做最终决策，而是帮助成员沉淀高质量工作对话、总结可蒸馏经验、标记质量星级，并按固定格式保存训练语料。

你必须在每次对话结束时输出：
1. 本次任务类型
2. 业务线
3. 可蒸馏经验点
4. 质量星级：一星 / 二星 / 三星
5. 是否建议进入本期蒸馏
6. 推荐归档标题

判断标准：
- 一星：普通记录，只留档。
- 二星：有明确业务经验，可进入蒸馏候选。
- 三星：包含高价值判断、评审标准、内部方法论，优先进入蒸馏。

如果成员给出的内容不完整，你要主动追问背景、判断理由、取舍标准和最终结论。
```

## 成员使用方式

成员不需要“喂资料”式对话，而是直接把日常工作拿进来做。

例如：

```markdown
今天我要评审一个金龙主题 Slot 的 Free Spin 方案，你先帮我列出评审维度，我会边看边给你我的判断。
```

或者：

```markdown
这是我刚写的策划案初稿，你帮我检查结构和遗漏点。检查后，把这次可蒸馏经验总结出来。
```
