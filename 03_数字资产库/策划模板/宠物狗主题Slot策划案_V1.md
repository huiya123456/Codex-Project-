# 宠物狗主题 Slot 策划案 V1

## 版本信息

- 项目代号：Corgi Backyard
- 中文名：柯基波比的后院冒险
- 英文名：Corgi Bobby's Backyard
- 游戏类型：竖屏单机 Slot
- 目标分辨率：1080 x 1920
- 基础布局：3 列 x 3 行
- 特色副玩法：免费游戏、重转彩金游戏、手动对齐中奖、宠物收集进度
- 主题定位：宠物狗、后院冒险、可爱卡通、轻喜剧
- 适用版本：单机展示版 / Demo 原型版 / 美术需求拆解版

## 1. 核心体验定位

本项目是一款以威尔士柯基犬“波比”为主角的竖屏 Slot。玩家通过旋转卷轴收集狗粮盆、玩具箱和后院徽章，逐步触发免费游戏、彩金重转和公共收集奖励。核心体验不是传统自动赔付，而是加入“手动推动列”的轻交互：当卷轴形成潜在中奖时，玩家需要选择上移或下移，把第三个同类图标对齐到中央中奖线。

设计目标：

- 让普通旋转有轻判断和参与感，而不是纯等待。
- 用宠物收集行为解释 Scatter、Bonus、Link 三类进度。
- 让免费游戏和彩金游戏在场景上形成“从后院跑出去冒险”的连续故事。
- 美术表达以清晰、明亮、亲和为主，避免复杂暗色或厚重写实风。

## 2. 世界观与故事

波比是一只活泼好动的威尔士柯基犬。主人出门后，它从后院悄悄溜出去，把骨头、网球、飞盘、袜子和玩具熊一路叼回家。每次旋转都像波比在后院翻找新玩具；当它收集到足够狗粮或玩具，就会跑到街道和公园继续冒险。

场景推进：

1. 主游戏：白天后院。草地、木栅栏、狗窝、土坑、玩具散落。
2. 免费游戏：街道路边。人行道、井盖、路牌、商铺、青蛙惊喜。
3. 彩金游戏：黄昏公园。长椅、路灯、灌木、玩具宝藏箱。
4. 大奖表现：波比叼着玩具冲入画面，彩带、骨头金币和蝴蝶特效爆发。

本策划案统一采用 3 档彩金：

- MINI：绿色网球，低档固定彩金。

说明：原参考案中存在 3 档与 5 档彩金混用。本版优先采用 3 档，降低单机 Demo 和首版美术工作量。如果后续扩展商业版，可追加 MEGA 和 GRAND，但需同步更新彩金栏、图标、奖框、结算和资源表。

## 5. 基础玩法

### 5.1 主游戏规则

- 卷轴为 3 列 x 3 行。
- 中奖线只有中央横线 1 条。
- 每次 Spin 后，每列停止在 3 个可见符号。
- 普通中奖需要中央中奖线形成 3 个相同普通图标，或由 Wild 替代后成立。
- 当系统判定存在“可推动成奖”的局面时，不立即结算，显示推动按钮。
- 每次 Spin 最多允许一次推动操作。
- 玩家选择正确方向后完成中奖；选择错误方向则本次不中奖。
- 若本次不存在可推动成奖局面，则 Spin 结束后直接进入下一次操作。

### 5.2 手动推动列规则

触发条件：

- 中央中奖线上已有 2 个相同可中奖图标。
- 第 3 个相同图标位于剩余列的上格或下格。
- 该图标不是 Scatter、Bonus、Link、彩金或奖金符号。

按钮显示：

- 若目标图标在上格，显示 DOWN 按钮，使该列下移一格。
- 若目标图标在下格，显示 UP 按钮，使该列上移一格。
- 为避免 RISE、RAISE、LOWER 混用，本版统一使用 `UP` 与 `DOWN`。

失败处理：

- 玩家选择错误方向，本次中奖失败。
- 错误操作后不允许二次修正。
- 失败时播放波比疑惑表情和轻微抖动反馈。

### 5.3 赔付规则

- 主游戏只赔付最高一条中奖结果。
- Scatter、Bonus、Link 不参与普通线奖。
- Wild 可替代低价值和高价值符号。
- 免费游戏中允许 Sticky Wild，不改变基础赔线规则。
- 所有赔付基于当前总押注倍率计算。

## 6. 收集系统

主游戏界面包含 3 个收集进度：

| 收集项 | 来源符号 | 阶段 | 满进度效果 |
|---|---|---|---|
| 狗粮盆 | Scatter | 0/10/20/30 | 解锁免费游戏触发资格 |
| 玩具箱 | Bonus | 0/10/20/30 | 解锁彩金游戏触发资格 |
| 后院徽章 | Link | 0/15/30 | 解锁公共奖励展示，Demo 版可表现为金币小奖 |

收集表现：

- Scatter 飞向狗粮盆，狗粮逐步堆满。
- Bonus 飞向玩具箱，玩具逐步溢出。
- Link 化为彩色流光飞入徽章进度条。
- 满进度后保持最高状态，直到对应功能被触发并结算。

触发口径：

- 满进度只代表“获得触发资格”，不等于下一局必进。
- Demo 版建议满进度后 3 次 Spin 内保底触发，避免测试体验过长。
- 商业版可由数值表配置真实概率和保底。

## 7. 免费游戏

### 7.1 触发条件

满足任一条件触发免费游戏：

1. 狗粮盆收集达到 30 后，在后续 Spin 中出现免费游戏触发判定。
2. 中央中奖线同时出现 3 个 Scatter。

Demo 建议：

- 狗粮盆满进度后，每次 Spin 有 35% 概率触发。
- 连续 3 次未触发时，第 4 次强制触发。

### 7.2 免费次数获取

进入免费游戏前，播放“道路小青蛙”次数获取小游戏：

- 使用 2 列 x 3 行，共 6 个井盖青蛙。
- 每个井盖停止后显示 1、2 或 3 次。
- 最终免费次数为 6 个数字之和。
- 免费次数范围：9 到 12 次。

说明：原参考案中出现 6 个与 9 个井盖冲突。本版统一为 6 个，符合 2x3 的视觉和操作空间。

### 7.3 免费游戏规则

- 卷轴仍为 3x3。
- 使用街道路边背景。
- 免费游戏期间不消耗押注。
- 免费游戏中 Wild 具有粘性机制。
- 当任意位置同时出现 2 个 Wild 时，这 2 个 Wild 固定在原位置，持续最多 4 次免费旋转。
- 粘性 Wild 持续结束后移除。
- 免费游戏结束后显示结算框，再转场回主游戏。

### 7.4 免费游戏美术表现

- 波比从后院栅栏跳出，转场到街道。
- 背景亮度略降，突出卷轴和 NPC。
- 云朵缓慢移动，商铺灯牌轻微闪烁。
- Wild 固定时用网球弹跳和金色爪印锁定特效。

## 8. 彩金游戏

### 8.1 触发条件

满足任一条件触发彩金游戏：

1. 玩具箱收集达到 30 后，在后续 Spin 中出现彩金游戏触发判定。
2. 中央中奖线同时出现 3 个 Bonus。

Demo 建议：

- 玩具箱满进度后，每次 Spin 有 30% 概率触发。
- 连续 4 次未触发时，第 5 次强制触发。

### 8.2 彩金重转规则

- 彩金游戏卷轴为 5 行 x 3 列，共 15 格。
- 初始重转次数为 3 次。
- 出现金额骨头或彩金球时，该符号固定在当前位置。
- 每次新增固定符号后，重转次数重置为 3。
- 未新增固定符号时，重转次数减 1。
- 重转次数归 0 时进入结算。

### 8.3 C/O/R/G/I 字母收集

- 彩金游戏左侧有 5 个字母：C、O、R、G、I。
- 每一行 3 个格子全部被固定符号填满时，点亮对应行字母。
- 5 个字母全部点亮时，额外奖励 MAJOR。
- 该奖励只在本轮彩金游戏中触发一次。

### 8.4 Bonus 收集列规则

- 彩金游戏中 Bonus 图标可出现并固定。
- Bonus 固定后，立即收集所在列已有的金额骨头。
- 被收集的金额骨头数值加入结算池，位置仍保持已填充状态。
- Bonus 不收集彩金球。

### 8.5 彩金结算

结算内容：

- 所有金额骨头累计值。
- 获得的 MINI、MINOR、MAJOR 固定彩金。
- 若集齐 C/O/R/G/I，追加 MAJOR。

结算表现：

- 金额骨头逐个飞入结算框。
- 彩金球按 MINI、MINOR、MAJOR 顺序展示。
- 若触发全字母奖励，波比叼出礼物盒，弹出 MAJOR 奖励提示。

## 9. 大奖提示

大奖提示按单次中奖金额与总押注倍数判定：

| 档位 | 触发条件 | 表现 |
|---|---|---|
| BIG WIN | >= 5x 总押注 | 骨头金币喷出，波比摇尾跳跃 |
| SUPER WIN | >= 10x 总押注 | 彩带、蝴蝶、金币堆增强 |
| MEGA WIN | >= 20x 总押注 | 全屏闪光，波比冲入前景欢呼 |

规则：

- 若同一次结算跨越多档，按 BIG -> SUPER -> MEGA 逐级播放。
- 免费游戏总赢分在返回主游戏前统一判定大奖。
- 彩金游戏总赢分在彩金结算后统一判定大奖。

## 13. 程序需求说明

### 13.1 配置表

建议拆分以下配置：

| 配置表 | 说明 |
|---|---|
| BetConfig | 押注档位、默认押注、最小最大押注 |
| SymbolConfig | 符号 ID、类型、权重、是否可 Wild 替代 |
| PaytableConfig | 符号赔付倍率 |
| ReelStripConfig | 主游戏、免费游戏、彩金游戏卷轴条 |
| CollectConfig | 三类收集进度、满进度阈值、保底次数 |
| FeatureTriggerConfig | 免费、彩金、Link 奖励触发概率 |
| FreeGameConfig | 免费次数范围、井盖数字权重、Sticky Wild 持续次数 |
| JackpotConfig | MINI/MINOR/MAJOR 固定值或倍率 |
| BigWinConfig | BIG/SUPER/MEGA 阈值 |
| AnimationConfig | 动效 key 与资源路径映射 |

### 13.2 核心系统

- Spin 状态机：Idle、Spinning、ResultCheck、NudgeWait、Payout、FeatureEnter、FeaturePlaying、FeatureExit。
- 手动推动系统：检测可推动列、显示方向、处理正确/错误结果。

## 16. 说明书文案

### 16.1 主游戏

点击 Spin 开始旋转。中央横线为唯一中奖线。当两个相同图标已在中奖线上，第三个相同图标位于相邻上格或下格时，选择 UP 或 DOWN 将图标对齐。选择正确方向即可获得奖励，选择错误方向则本次不中奖。

Wild 可替代普通图标。Scatter 会收集到狗粮盆，Bonus 会收集到玩具箱，后院徽章会推进公共收集进度。

### 16.2 免费游戏

收集狗粮盆进度或获得 3 个 Scatter 可触发免费游戏。进入免费游戏前，井盖青蛙会决定免费旋转次数。免费游戏中，两个 Wild 同时出现时会固定在卷轴上，持续最多 4 次旋转。

### 16.3 彩金游戏

收集玩具箱进度或获得 3 个 Bonus 可触发彩金游戏。彩金游戏为 5x3 重转玩法。金额骨头和彩金球出现后会固定，新增固定符号会将重转次数恢复为 3。填满一整行会点亮对应字母，集齐 C/O/R/G/I 可获得额外 MAJOR。

## 17. 测试验收点

### 17.1 玩法验收

- 主游戏能正常 Spin、停轴、判奖、结算。
- 可推动局面能正确识别 UP/DOWN。
- 正确推动产生中奖，错误推动不中奖。
- 每次 Spin 最多只允许推动一次。
- Scatter、Bonus、Link 能分别进入对应收集进度。
- 收集满进度后能按配置触发功能和保底。
- 免费游戏次数范围稳定在 9 到 12。
- Sticky Wild 出现、固定、持续和移除正确。
- 彩金重转次数能正确重置和递减。
- C/O/R/G/I 点亮逻辑正确。
- 集齐字母后只奖励一次 MAJOR。

### 17.2 UI 验收

- 竖屏 1080x1920 下底部 UI 不遮挡卷轴。
- 弹窗按钮可点击区域清晰。
- 长文本不溢出按钮和弹窗。
- 说明书分页清楚，中文文案无占位符。
- Auto 遇到手动推动时能暂停。

### 17.3 美术验收

- 三个场景在色彩和空间上有明显区分。
- 波比形象在各界面保持一致。
- 符号缩小到卷轴尺寸后仍可辨认。
- Scatter、Bonus、Wild 与普通图标有明显功能差异。
- 彩金球 MINI、MINOR、MAJOR 颜色和形状可区分。

## 18. 风险与待确认

| 风险 | 影响 | 建议 |
|---|---|---|
| 手动推动增加理解成本 | 玩家可能不知道为何不能继续 Spin | 首次出现时加短提示和波比指引 |
| 3 档彩金与商业预期不一致 | 后续若要求 5 档需返工 | 立项前确认是否保留 3 档 |
| 收集满后概率触发体验不稳定 | Demo 展示可能等待过长 | Demo 使用保底触发 |
| 波比动作数量较多 | 动画成本高 | 首版保留关键 6 个动作，其余二期补充 |
| 免费游戏 Sticky Wild 和彩金重转同时复杂 | 程序状态较多 | 先完成主流程，再接入特殊表现 |

## 20. 与参考案相比的统一调整

- 彩金统一为 3 档：MINI、MINOR、MAJOR。
- 免费游戏井盖青蛙统一为 2x3，共 6 个。
- 推动按钮统一为 UP / DOWN，避免 RISE、RAISE、LOWER 混用。
- 删除魔法、法师、戒指等非宠物主题残留资源。
- 将“有几率”改为可配置概率和保底次数。
- 将 Demo 必要调试项写入程序需求，方便开发和验收。
- 将资源清单按静态、动态拆分，并降低首版必做范围。
