# 水果777 HTML Demo代码模块

## 模块说明

该模块沉淀水果777 V1的原生Web Demo实现，适合作为后续Slot原型的起点。

## 源文件

- `04_Demo基准测试/Demo_V1_水果777_20260514/demo/index.html`
- `04_Demo基准测试/Demo_V1_水果777_20260514/demo/styles.css`
- `04_Demo基准测试/Demo_V1_水果777_20260514/demo/app.js`

## 可复用点

- 3x3卷轴渲染。
- 带权重的随机符号抽取。
- 5条赔线检测。
- Wild替代、Scatter免费旋转、Bonus虚拟奖池。
- 无依赖CSS动效和移动端适配。
