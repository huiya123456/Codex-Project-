# 公司游戏研发数字资产库

## 分类

| 资产类型 | 存放位置 | 内容说明 | 复用方式 |
|---|---|---|---|
| 提示词资产库 | `提示词` | GPT Image 成功提示词和效果评级 | 同类任务复用 A 级提示词 |
| 策划模板库 | `策划模板` | 验证过的 Slot / 文审机 / 大厅策划案框架 | 新项目套模板后填差异 |
| 美术风格包 | `美术风格包` | 视觉风格参考包、提示词、生成图 | 同主题或同市场项目复用 |
| 代码模块库 | `代码模块` | Unity 可复用功能模块 | 新项目调用已验证模块 |
| 测试用例库 | `测试用例` | 通用测试用例模板 | 新项目补差异项 |
| Demo基准档 | `Demo基准` | 每次 Demo 完整输出物和评分表 | 对比蒸馏前后能力 |
| 蒸馏语料库 | `蒸馏语料库` | 按岗位分类的高质量对话语料 | 持续投喂对应智能体 |

## 质量评级

- A级：直接复用，不需要人工修改即可用于实际项目。
- B级：参考复用，需要少量调整。
- C级：留档参考，需要较多调整。
- 不入库：质量不达标，直接淘汰。
