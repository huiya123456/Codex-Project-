# 公司游戏研发 AI 全链路智能体工作台

本工作台依据《Codex全链路AI操作手册V2》初始化，用于沉淀 18 个岗位智能体、3 个训练数据区、数字资产库、Demo 基准测试和半月蒸馏 SOP。

## 当前落地内容

- `00_执行中枢`：三阶段路线、总架构、执行检查清单、AI 与人工边界。
- `01_智能体配置`：18 个智能体的建议命名、项目说明、输入输出和系统提示词。
- `02_训练数据`：成员 A/B/C 的训练数据收集区。
- `03_数字资产库`：提示词、策划模板、美术风格包、代码模块、测试用例、Demo 基准、蒸馏语料库。
- `04_Demo基准测试`：Lucky Golden Dragon 零蒸馏 Demo 测试任务、完整输出和评分表。
- `05_蒸馏SOP`：半月蒸馏节奏、指令模板和记录表。
- `06_模板库`：日常复用模板。

## 推荐使用顺序

1. 先打开 `00_执行中枢/初始化执行检查清单.md`，逐项核对架构是否符合公司实际。
2. 将 `01_智能体配置` 中每个文件的「系统提示词」复制到对应 Codex 子项目的自定义说明。
3. 使用 `04_Demo基准测试/Demo任务书.md` 启动零蒸馏 Demo，并把真实输出填入评分表。
4. 每天把成员 A/B/C 的高质量工作对话放入 `02_训练数据`。
5. 每月 1 日和 16 日按 `05_蒸馏SOP/半月蒸馏SOP.md` 执行蒸馏。
6. 每轮蒸馏后重新运行同一个 Demo，保存到 `03_数字资产库/Demo基准`，用于对比能力提升。

## 关键原则

- Demo V0 是永久基准，不能删除。
- AI 输出可以作为初稿和结构化资产，最终立项、上线、合同、客户沟通和资金安全相关代码必须人工审批。
- 每个能复用的提示词、模板、测试用例和代码模块，都要进入数字资产库并评级。

## 多人协作

本项目建议通过 Git 远程仓库同步给团队成员使用。每个成员在自己的电脑 clone 仓库，再用 Codex 打开本地项目目录。

详细规则见 `00_执行中枢/团队多人使用说明.md`。
