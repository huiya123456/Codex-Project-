# AI 与人工分工边界

| 环节 | AI 可完成 | 必须人工介入 |
|---|---|---|
| 客户需求 | 需求解析、结构化、立项书、风险识别、补充追问 | 最终立项确认、真实客户沟通协商 |
| AI项目经理 | 工作计划、任务分配、进度汇总、风险识别 | 最终决策、工期压缩、资源调配 |
| Slot策划 | 策划案初稿、多方案比较、竞品分析、需求文档 | 创意拍板、RTP 最终确认、上线前审批 |
| 文审机策划 | 玩法初稿、平衡方案、规则文档 | 玩法体验判断、运营协调决策 |
| 美术生成 | 概念图、提示词优化、视觉方向初稿 | 最终视觉审定、客户提案确认、精修指导 |
| 动画规范 | 动画规范、状态清单、参数建议 | 实际动作效果判断 |
| 特效方案 | 特效方案、参数建议、性能评估 | 真机视觉效果确认 |
| 3D模型 | 建模规范、验收标准、命名检查 | 实际模型外观质量判断 |
| Unity搭建 | 资产导入规范、场景方案、性能报告 | 实际 Unity 场景效果确认、特殊 Shader 开发 |
| 程序开发 | 技术方案、代码框架、伪代码 | 代码安全审查、复杂逻辑、服务器后端 |
| 音效 | 音效清单、风格规范、接入文档 | 实际音频内容制作 |
| 测试 | 测试用例、RTP 计算、Bug 分级标准 | 游戏体验主观测试、边缘案例判断 |
| 上线 | 排期甘特图、上线检查清单核查 | 最终上线审批 |

## 永远需要人工的环节

- 最终上线审批。
- 与客户直接谈判和合同签署。
- 实际音频内容制作。
- 极度主观的视觉体验判断。
- 涉及资金、安全、服务器后端的代码审查和开发。
