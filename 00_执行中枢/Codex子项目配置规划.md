# Codex 子项目配置规划

本文用于指导你在 Codex 中创建并配置 18 个岗位智能体窗口，以及 3 个训练数据窗口。

## 总体建议

- 主项目名称：公司游戏研发AI全链路总项目
- 子项目数量：18 个岗位智能体 + 3 个训练数据窗口
- 建议先创建“链路入口”和“策划环节”，再创建美术、技术、测试和项目管理。
- 所有岗位智能体的系统提示词来自 `01_智能体配置`。
- 训练数据窗口不放复杂系统提示词，重点用于沉淀成员真实对话和人工总结。

## 每个岗位智能体的配置方法

1. 在 Codex 中新建一个窗口或子项目。
2. 名称按上表填写，例如 `01-客户需求智能体`。
3. 打开对应配置文件。
4. 复制配置文件中 `## 系统提示词` 以下的全部内容。
5. 粘贴到该 Codex 子项目的自定义说明或系统说明位置。
6. 在窗口第一条对话中粘贴下面的初始化确认指令。

```markdown
请确认你已经进入本岗位角色。请用以下格式回复：

【岗位名称】
【你负责的输入】
【你必须输出的内容】
【需要人工确认的边界】
【你将如何配合全链路其他智能体】
```

## 训练数据窗口配置方法

训练数据窗口不是用来让 AI 独立产出最终方案的，而是用来让真实成员和 AI 一起工作、沉淀可蒸馏经验。

建议给训练数据窗口放入以下简短说明：

```markdown
你是公司AI训练数据记录助手。你的任务不是替代成员做最终决策，而是帮助成员沉淀高质量工作对话、总结可蒸馏经验、标记质量星级，并按固定格式保存训练语料。

每次对话结束后，请输出：
1. 本次任务类型
2. 可蒸馏经验点
3. 质量星级：一星 / 二星 / 三星
4. 是否建议进入本期蒸馏
5. 推荐归档标题
```
