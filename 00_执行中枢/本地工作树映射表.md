# 本地工作树映射表

本文说明本地 Git 分支和 worktree 的规划。它用于弥补当前 Codex 桌面环境无法直接自动创建 Codex 子项目窗口的限制。

## 总控仓库

- 总控目录：`E:\Project`
- 主分支：`main`
- Worktree 根目录：`E:\Project_Worktrees`

## 使用方式

每个智能体或训练数据区都有一个独立 worktree。你可以在 Codex 中分别打开这些 worktree 目录，把它们当作“子项目窗口”使用。

如果某个岗位要长期训练或持续产出，就在对应 worktree 中工作；总控目录 `E:\Project` 只维护全局手册、配置、模板和资产库主版本。

## 合并建议

- 岗位智能体分支的成熟模板、提示词改动，可以定期合并回 `main`。
- 训练数据分支不要直接合并原始敏感对话到 `main`，建议只合并脱敏后的蒸馏总结。
- Demo V0 基准资料不要覆盖，后续对比新建 Demo V1、Demo V2。
