# 本地工作树映射表

本文说明 Git 分支和 worktree 的规划。它用于弥补当前 Codex 桌面环境无法直接自动创建 Codex 子项目窗口的限制。

## 使用原则

- 远程仓库保存团队共享版本。
- 每个成员在自己的电脑 clone 仓库。
- worktree 是每个成员本机的可选增强，不是团队共享路径。
- 公共文档只记录分支名和建议目录名，不写死某台电脑的盘符。

## 建议目录

假设成员本地项目目录为：

```text
<ProjectRoot>
```

建议将 worktree 根目录放在项目同级：

```text
<ProjectRoot>_Worktrees
```

例如某成员把项目放在 `<任意本地目录>\Project`，则 worktree 根目录可设为 `<任意本地目录>\Project_Worktrees`。

## 本机创建示例

```powershell
$ProjectRoot = "<你的本地项目目录>"
$WorktreeRoot = "<你的本地worktree目录>"
New-Item -ItemType Directory -Force $WorktreeRoot
git -C $ProjectRoot worktree add "$WorktreeRoot\03_slot_planner" agent/03-slot-planner
```

## 合并建议

- 岗位智能体分支的成熟模板、提示词改动，可以定期合并回主分支。
- 训练数据分支不要直接合并原始敏感对话到主分支，建议只合并脱敏后的蒸馏总结。
- Demo V0 基准资料不要覆盖，后续对比新建 Demo V1、Demo V2。
