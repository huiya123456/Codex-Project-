# 成员整理本周对话记录：Codex 固定指令

## 先说明边界

Codex 通常不能稳定读取左侧其他历史对话的完整内容。

所以成员需要先把要整理的对话放到自己的 `00_待整理对话` 目录中。可以是：

- 从 Codex 历史对话中复制出来的 `.md` 文件
- 从 Codex 历史对话中复制出来的 `.txt` 文件
- 当前对话中直接让 Codex 保存出来的记录文件

成员不需要自己归纳总结，只需要把原始对话放进去，然后触发下面这条指令。

## 成员A Slot策划固定指令

```text
请读取 02_训练数据/T-A_成员A_Slot策划方向/00_待整理对话 下本周新增的所有 .md 和 .txt 对话记录。

请不要直接全量复制原文，而是按训练蒸馏用途自动归纳，输出到：
02_训练数据/T-A_成员A_Slot策划方向/01_原始整理记录/YYYY-WW_成员A_Slot策划_本周对话整理.md

整理要求：
1. 按对话主题分组。
2. 提取成员真实工作问题、判断过程、取舍标准、最终结论。
3. 生成可用于训练的高质量问答。
4. 标记质量等级：A / B / C。
5. 标记是否建议进入蒸馏候选：是 / 否。
6. 明确列出需要人工复核的问题。
7. 不要把低质量闲聊、重复内容、无结论讨论写入训练问答。
8. 输出完成后，告诉我本次读取了哪些源文件、生成了哪个目标文件。
```
